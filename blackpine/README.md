# Blackpine — The Last Signal

A procedural-vector survival RPG with scavenging, firearms, progression and touch controls. This is the current saved build of the Site originally named **Vector Vale**.

- Play: [index.html](index.html)
- Original working Site: https://vector-vale.x-nihilo.chatgpt.site
- Recovered saved version: **2**, commit `2fa411dae640f6bd5c49aeaf81e4191e1ed63cee`.
- Complete original source: [source/sites-source.tar.gz](source/sites-source.tar.gz).

The playable HTML is byte-for-byte identical to the saved source's `dist/index.html`. It runs entirely in the browser, with no account, server, package install or external runtime dependency. The original Site and its history remain unchanged. Serve this folder over HTTP or open `index.html` directly.

Move with WASD / arrow keys, aim with the mouse and fire with the mouse button; follow the in-game start screen for the complete keyboard and touch controls.

`source/preview-v1.jpeg` is retained only as a historical screenshot of the preceding Vector Vale build, not a preview of current Blackpine.
