# Inkstar — early Inkdrift

Inkstar is an early generation of the Inkdrift project. These builds are preserved as historical versions.

[Play current Inkdrift](../../) · [Archive overview](../)

- `index.html`: standalone polish demo with cartoon spaceflight, destinations, trading, missions, and ship services.
- `versions/github-fleet/`: former GitHub homepage, including its loader and zero-cost ships and paint.
- `versions/earlier-runtime/`: earlier scripts retained as source snapshots.

Application files are unchanged from the previously published Inkstar builds.
